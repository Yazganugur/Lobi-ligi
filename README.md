# Lobi Ligi

Ana site: https://yazganugur.github.io/Lobi-ligi/

GitHub Pages siteyi, Supabase hesapları ve ortak sosyal/lobi verilerini çalıştırır. Üretim dalı main, yayın klasörü deponun köküdür.

Sezon 2 varsayılan; Sezon 1 üstteki seçiciden açılır. Kart Overall’ı 60–99, rol değerleri 0–100. Yeni sezon kartı için beş geçerli demo gerekir. Puan Sistemi sekmesi formülleri ve sınırları açıklar.

Herkese açık profiller, arkadaşlık ve özel mesajlar, lobi geceleri, hazır olma/yönetim devri, demo round hikâyeleri, gelişim rotası ve indirilebilir sezon albümü içerir. Sosyal işlemler onaylı oyuncu hesabı gerektirir.

Hesabım menüsü tam sayfa profil, arkadaşlar, mesajlar, bildirimler ve hesap ayarlarına açılır. Maç arşivi sayfalıdır; telefonda kompakt kartlara dönüşür.

Lobi gecelerinde sorumlu tarih/saat belirler. İlk 10 kişi ana kadroya, sonrakiler katılma sırasıyla yedeğe geçer. Ayrılma, yeniden katılma ve yedekten yükselme geçmişi korunur; zamanlar Türkiye saatidir. Takvim dosyası, saat oylaması, maç öncesi hazır bildirimi ve geceye maç bağlama bulunur. Gece ödülleri kozmetiktir, Elo veya Overall değiştirmez.

Güncellemelerde yeni index.html bu depoya hazırlanır. GitHub Desktop’ta Commit to main → Push origin yeterlidir. Push sonrası GitHub Pages yeniden yayımlar. league-config.json yalnız kamuya açık Supabase bağlantısını taşır; özel anahtar ve şifreler depoya konmaz.
